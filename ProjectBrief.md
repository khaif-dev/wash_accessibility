# Water Point Accessibility in Migori County, Kenya

## Spatial Question

How accessible are functional water points to the population of Migori County, and which areas have the greatest gaps in access?

## Why it matters

Access to water points is an important component of community well-being and service delivery. However, the presence of water points does not necessarily mean that populations are equally able to reach and use them.

## Data and Data Sources

| Dataset                       | Description                                                                                               | Source                                                                                                                     |
| ----------------------------- | --------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **Water Points**              | Water-point locations and attributes used to identify functional water points                             | [Water Point Data Exchange (WPDx) – Kenya Data](https://data.waterpointdata.org/dataset/Kenya-Data/e2gs-xfxf/data_preview) |
| **Administrative Boundaries** | Administrative boundaries used to extract the Migori County study area                                    | [Humanitarian Data Exchange – Kenya Elections / IEBC Data](https://data.humdata.org/dataset/kenya-elections)               |
| **Population**                | Gridded population estimates used to assess population distribution and population-weighted accessibility | [WorldPop – Kenya Geospatial Data](https://hub.worldpop.org/geodata/country?iso3=KEN)                                      |
| **Road Network**              | Road network used to assess accessibility along available routes                                          | [OpenStreetMap](https://www.openstreetmap.org/)                                                                            |
## Expected Outputs

The project will produce an interactive WASH accessibility dashboard that enables MEAL Officers to assess the accessibility of functional WASH facilities across Migori County during baseline surveys.
